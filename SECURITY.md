# Security policy

zt-memory runs locally and is designed to keep excluded files away from any LLM. If you find a way to make the
index, the MCP tools or `zt code` expose a file covered by `exclude_globs`, a hidden file, a git-ignored file or a
path outside the project, please report it privately through
[GitHub Security Advisories](https://github.com/Giotor84/zt-memory/security/advisories/new) instead of a public issue.
